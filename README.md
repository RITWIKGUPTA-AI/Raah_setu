# RaahSetu

**Every Road. Every Second.**

A government logistics and emergency operations dashboard for the North Eastern Region. It tracks road disruptions, incidents, fleets, shipments and district connectivity on one live map.

**Live demo:**https://raahsetu.vercel.app/

## Features

- Command dashboard with a live GIS map, KPIs and priority alerts
- Incident management and field reports
- Fleet tracking, logistics and shipments
- Route intelligence and district connectivity monitoring
- AI risk outlook and analytics views

> This is a frontend prototype. All data shown is sample data.

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Copy `.env.example` to `.env.local` and add your MapTiler key:
   `VITE_MAPTILER_API_KEY=your_key`(You can use your api as it is highly credential)
3. Run the app:
   `npm run dev`

## Built with

React, TypeScript, Vite, Tailwind CSS, MapLibre GL, Recharts

## Deployment

Hosted on Vercel. Build command `npm run build`, output directory `dist`.
